# WebP Export (with max size) (Figma Plugin)

Плагин экспортирует выделенные фреймы/компоненты/группы/секции в `.webp` с ограничением максимального веса файла в KB.
Лимит считается в десятичных `KB` (`1 KB = 1000 bytes`) — как в Finder.

## Что делает
- Берет все подходящие выделенные элементы.
- Экспортирует каждый элемент из Figma в PNG.
- В UI конвертирует в WebP.
- Подбирает максимально возможное качество, чтобы файл был не больше заданного лимита.
- Если только качеством не удается уложиться в лимит, уменьшает размер изображения (scale) и повторяет подбор качества.

## Установка
1. Откройте Figma Desktop.
2. Перейдите в `Plugins` -> `Development` -> `Import plugin from manifest...`.
3. Выберите файл:
   - `figma-webp-exporter/manifest.json`

## Использование
1. Выделите 1+ фреймов (или компонент/группу/секцию).
2. Запустите плагин `WebP Export (with max size)`.
3. Введите лимит, например `150`.
4. Нажмите `Экспортировать`.
5. Все `.webp` скачаются одним `.zip` архивом.
6. Имя архива включает дату/время и лимит, например: `webp-export-2026-04-27-1530-150kb.zip`.

## Ограничения
- В браузерной части плагина скачивание нескольких файлов может запросить подтверждение у браузера/системы.
- На очень сложных/больших фреймах процесс может занимать время.
