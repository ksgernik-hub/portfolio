# ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

- Это статический мультистраничный сайт-портфолио дизайнера (Ксюша Герник).
- Основная цель: презентация кейсов, резюме и контактов для клиентов/работодателей.
- Сайт двухязычный (EN/RU), по умолчанию английская версия.
- Проект временно защищен паролем на клиенте.

# ТЕХНОЛОГИИ

- Фреймворк: отсутствует (vanilla HTML/CSS/JS, без сборщика).
- Стили: основной общий файл `styles.css` + встроенные `<style>` в проектных страницах.
- JS:
  - `script.js` — главная страница (reveal-анимации, превью "Других проектов", кастомный курсор).
  - `i18n.js` — словарный перевод RU↔EN по текстовым узлам.
  - `password-gate.js` — пароль через `prompt`.
  - `protection.js` — блок context menu/drag/save/view-source для медиа.
- Внешние зависимости:
  - Google Fonts (Manrope).
  - Встраиваемые iframe видео/3D (Kinescope, Sketchfab) в отдельных кейсах.

# СТРУКТУРА ПРОЕКТА

- Корень:
  - `index.html` — главная.
  - `resume.html` — отдельная страница резюме.
  - `project-*.html` — отдельные страницы кейсов.
  - `styles.css` — глобальные стили главной/общие правила.
  - `script.js` — поведение главной.
  - `i18n.js` — языковой переключатель и словари.
  - `password-gate.js`, `protection.js` — доступ/защита медиа.
- Папка `images/`:
  - `projects/` — обложки главной и hover-превью "Других проектов".
  - `12edem-final/`, `fastino-final/`, `nefro-final/`, `viborg-final/`, `promo-final/`, `else-final/` — контент кейсов по согласованной схеме имен.
- Служебное:
  - `downloads/`, `figma-webp-exporter/`, `portfolio-site.zip` — не часть боевого рантайма сайта.

# ПРАВИЛА ДИЗАЙНА

- Стиль: минималистичный темный, аккуратные контрастные кейс-обложки.
- Типографика: Google Sans / Product Sans fallback + Manrope.
- Сетка:
  - Главная: CSS Grid, 5 колонок, комбинации full/2-3/3-2.
  - Кейс-страницы: mix full-width блоков + пары (`bigsquare/smallsquare`, `smallrect/bigrect`).
- Цвета: база `#151515` фон, светлый текст, muted-серые подписи.
- Анимации:
  - Главная: reveal при скролле + fallback принудительного показа при `load/pageshow/resize`.
  - Кастомный курсор-точка на desktop.
  - Hover-эффекты деликатные (brightness).

# ВАЖНЫЕ ОГРАНИЧЕНИЯ

- Не менять согласованную структуру имен файлов кейсов:
  - `N-full`, `N-left-bigsquare`, `N-right-smallsquare`, `N-left-smallrect`, `N-right-bigrect`.
- Не ломать текущую сетку и порядок карточек на главной.
- Не удалять `i18n.js`, `password-gate.js`, `protection.js` без отдельного решения.
- Не переводить проект на другой стек (React/Next) без явного запроса.

# ИЗВЕСТНЫЕ ПРОБЛЕМЫ

- Перевод через обход текстовых узлов хрупкий:
  - возможны пропуски строк в EN/RU (если новые фразы не добавлены в словарь).
- На встраиваемых iframe (видео/3D) кастомный курсор может работать нестабильно (события мыши внутри iframe недоступны родителю).
- "Защита от скачивания" клиентская и обходится технически.
- В проекте есть временные/служебные папки и файлы, которые могут путать при коммите.

# ТЕКУЩИЕ ПРИОРИТЕТЫ

- Доводка контента кейсов (замены медиа, порядок блоков, размеры small/big пар).
- Поддержание консистентности EN/RU: добавлять новые строки в `i18n.js` сразу при изменениях.
- Проверка адаптива и визуальной сетки после каждой серии правок.
- Поддержание чистоты репозитория (не коммитить служебные артефакты).

# КАК РАБОТАТЬ С ПРОЕКТОМ

Инструкция для AI:

- Не переписывай весь проект целиком.
- Меняй только нужные файлы.
- Сохраняй текущую структуру.
- Сначала объясняй, что будешь менять, потом предлагай код.
- После правок всегда:
  - проверь порядок медиа-блоков по именам файлов,
  - проверь EN/RU для новых текстов,
  - дай пользователю список файлов для пуша.
